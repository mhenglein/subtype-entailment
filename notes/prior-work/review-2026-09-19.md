## Read this first

The target is entailment over **bottom and one covariant binary product**, with
variables ranging over **arbitrary, possibly infinite trees**. Removing the top
constructor does not remove the greatest infinite binary tree. Keep distinct:

- finite constraint syntax versus finite type valuations;
- regular infinite countermodels versus finite countermodels;
- deciding existence of a witness versus recognizing every witness word;
- an exact finite supplied formula versus a complete effective family of formulas;
- literal word equality versus state-coloured, ordered comparisons.

These distinctions decide whether a paper is relevant. Read
[problem.md](../../research/problem.md) before any proposed transfer.

## What is already useful

The existing corpus has concrete local obstructions, source-linked theorem
locators, and explicit transfer gaps. Use it to eliminate precise invalid
inferences before investing in implementation. The strongest reusable feature
is the separation of **source result**, **local construction**, and **unproved
transfer**. Preserve that separation in every new note.

The core and adjacent reviews deepen selected primary passages. The periodic
review adds a direct route from the current infinite-branch question to word
periodicity and finite representations. The source register records which
passages were freshly inspected and which information remains historical or
metadata-only. Reading selected passages is not a complete proof review.

The discovery work is bounded. Search engines returning an old status page or
a withdrawn abstract do not establish the current state of the subject. A
source can be important without being a usable dependency, and a missing
archival proof remains an unresolved retrieval task.

## How an agent should choose an idea

1. Retrieve the closest topic using [the search tool](search.py). Read its
   source, relevant claims and failure modes; then follow exact evidence links.
2. Write the proposed implication with all quantifiers. State whether the
   attempt starts from known results, works backwards from the target, or both.
3. Name the nearest known counterexample and explain why the new hypothesis
   excludes it or why the target is weaker. “Uses another technique” is insufficient.
4. Choose one small falsification test or one disputed source transfer. Define
   an acceptable failure or UNKNOWN outcome before running a long search.
5. Claim the precise scope in the relevant issue. Keep source inspection,
   ordinary proof review, bounded experiments and formal verification distinct.
6. Return the result to the canonical record through the normal integration
   process. Search tags and literature cards do not change C/Q status.

An agent need not read every historical note on every invocation. The search
routes select a bounded reading packet. Mandatory project entry-point and
ownership checks still apply.

## Negative knowledge is conditional

Do not turn the failure catalogue into a blacklist of broad techniques.
Examples:

| Failed move | What it rules out | What may still work |
|---|---|---|
| Use endpoint, transition action and agreement profile as a complete reference quotient (F13) | That specific substitutivity claim | A richer invariant or an existence-preserving replacement theorem |
| Shorten a run merely because two states agree (C019, C028) | Unconditional deletion preserving witnesshood | A cut with a proved transport condition for new comparisons |
| Infer unique parsing from a finite/straight left language (F07) | The literal uniqueness claim | Prefix-free capture, with a separate downstream argument |
| Solve each query atom on its own extension (F18) | Independent reconstruction as proof of a conjunction | One common extension with all atom transports |
| Apply a solver to every proposed finite scheme (F23) | Completeness or termination without a cover | A separately proved effective cover |
| Use a safe cycle as the infinite-branch decision (F33) | Dropping the original witness predicate | A monitor that eliminates every surviving forbidden periodic future |

Each new failed attempt should save the exact preserved hypotheses, input,
independent checker and scope of the refutation. If a weaker statement remains
open, say so explicitly. See [failure-modes.md](failure-modes.md).

## Review method and limits

The parent and two source workers used the same exact problem statement and
existing dossiers. Their domains were disjoint: historical subtype lineage,
adjacent finite-word/query methods, and periodic continuations/navigation.
They inherited prior arguments; this is not a blind mathematical replication.
The parent reviews source summaries and the combined artifact before handoff.
Specific inspection and retrieval limits appear in each dossier and
[search-log.md](search-log.md). There is no author outreach, human referee,
paid-database search, or claim of exhaustive coverage in this pass.

The delivered retrieval code is checked for bounded output and correct record
linking. Such checks establish navigation behavior, not mathematical validity.
The final contribution records the checked revision and commands in
[validation-2026-09-19.md](validation-2026-09-19.md).
