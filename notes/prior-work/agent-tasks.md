# Bounded literature tasks for agents

These contracts expand [O01–O11](open-obligations.md). They do not assign an
owner or authorize a proof/source-system change. Read current scientific state
and coordination before claiming one. Return a source-linked artifact, not an
unstructured conversation summary.

## Periodic-suffix interface (O11)

**Question:** does the exact C029 monitor retain all and only the active
forbidden periodic futures for arbitrary safe entry prefixes?
**Read:** C026–C029, C031, the current `InfWitness` declaration;
[periodic review](dossiers/periodic-continuations-review-2026-09-19.md).
**Deliverable:** a definition-by-definition mapping with phase, reset, residue
and ordered-pair invariants; a primary periodicity theorem import only if used.
**Falsify first:** empty entry, period one, a last mismatch at either boundary,
a repeated state before acceptance, and a safe cycle reached without a witness.
**Stop/reopen:** preserve the first valid invariant counterexample. Reopen a
failed variant only with a changed invariant and an explanation of that example.
**Limit:** this literature task does not independently launch Lean work or decide
Problem 1.7. A finite test corpus cannot prove the monitor invariant.

## Withdrawn extension argument (O02)

**Question:** what exact premise/conclusion of Schubert v1 Lemma 5.5 is invalid?
**Read:** PW-SCH21 Definition 11, Proposition 5.4, Lemma 5.5 and the withdrawal
record; the [core review](dossiers/core-lineage-review-2026-09-19.md).
**Deliverable:** complete constraints, substitutions and positions satisfying
all premises and failing the conclusion; or a precise formulation-error analysis
with the unreconstructed step named. Include a premise checklist.
**Falsify first:** whether independently possible local extensions can coexist
in one substitution, without assuming this is the actual defect.
**Then:** compare that exact invariant with C080's joint extension contract.
**Stop:** an analogy is not a counterexample. If reconstruction fails, keep O02
open and preserve the attempted premises and search limits.

## Straight-language dependency audit (O01)

**Question:** how is the literal split lemma used in Chapter 11, and which
restricted replacement would actually suffice?
**Read:** PW-PRI04 definition of straightness and Lemmas 11.1/11.2/Theorem 11.1;
[existing example](dossiers/priesnitz-2004.md).
**Deliverable:** statement-level dependency map; independent source readback of
the finite example; exact sufficient replacement and unproved remaining uses.
**Falsify first:** distinguish accepting-state acyclicity from prefix-freeness.
**Stop:** do not call the chapter's final theorem false merely because its printed
lemma fails. Do not claim the whole proof repaired by adding prefix-freeness.

## Historical fragment comparison (O03/O04)

**Question:** do earlier decidable fragments cover a proposed Subtail subclass
through an admissible equivalent encoding?
**Read:** PW-NP99, PW-NP03, PW-BPR19, PW-PRI04 and the exact proposed C claim.
**Deliverable:** a source/target table of constructors, variance, valuation
semantics, query form, restriction, representation size and reduction direction.
Provide both directions where an equivalence is claimed. Name a failed direction.
**Discovery:** trace references and author publication lists for the 2019 result;
record version/date and whether a full proof was retrieved.
**Stop:** an example outside the old surface syntax does not prove non-subsumption.
Do not contact authors without explicit authorization.

## Whole-conjunction preimage comparison (O05)

**Question:** does a published theorem provide the same effective preimage for
the same graph transformation and output query grammar?
**Read:** PW-BFR19/PW-TF24, exact C080 statement and the current checked compiler
interfaces. Keep explicit weight bounds separate from semantic closure.
**Deliverable:** theorem locator, interpretation of each edge label and mark,
shared-variable policy, both semantic directions, closure and size guarantees.
**Falsify first:** inverse edges, zero-length paths, atoms sharing a physical
interval, multiple paths constrained by the same generator.
**Stop:** generic MSO closure or boundedness of expansions is not the required
transfer. Return the failed hypothesis match as useful negative evidence.

## Terminal-copy import (O06/O08)

**Question:** can a fixed matching or one-negated-containment theorem represent
the full target formula without changing its quantifiers?
**Read:** PW-KU26, PW-HHL25, PW-REGEX25, C077/C079 and F05/F06/F17/F26.
**Deliverable:** a finite formula with all variables and regular constraints,
outer candidate/cut quantifiers, terminal anchor and proper-overlap cases.
State the exact source theorem and complexity measure.
**Falsify first:** a word satisfying separate predicates with incompatible shared
assignments; a proper overlap omitted by a two-copy decomposition.
**Stop:** unresolved correction text remains a blocked source import, not a
reason to reject every related theorem. Matching examples are not containment.

## Citation and novelty pass (O09/O10)

**Question:** which existing theorem is closest to one exact proposed contribution?
**Deliverable:** two logged citation rounds, with accepted, rejected, duplicate
and inaccessible candidates. For each close candidate, compare statement and
semantics; record proof access and corrections. Deduplicate conference, preprint,
slides and journal versions by lineage.
**Stop:** after two rounds without a materially relevant lead, reassess the value
of more searching. This is a budget decision, not proof of exhaustive coverage.
**Final wording:** distinguish a reusable known theorem, a transfer not yet
proved, a candidate new result, and a contribution with matched prior art.
