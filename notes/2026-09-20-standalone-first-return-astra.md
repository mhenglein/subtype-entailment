## Route recorded before experiments

1. Replace the word-specific graph by an explicitly defined relational,
   finite-coloured graph and a finite-state first-hit generator. Define its
   extension by exact edge surgery, not by an assumed resemblance to KMP.
2. For each query atom delete repeated vertex/control configurations. Count
   fresh blocks by visits to a bounded set of fresh entrance vertices.
3. Mark positions globally across the entire conjunction. Compile old paths
   and portals locally; use a single synchronous generator product for every
   interval, with one coordinate per traversal, including repeated traversals.
4. Prove coverage by extracting a bounded diagram from one actual extension.
   Prove reconstruction by concatenating the chosen interval witnesses into
   one decorated generator before constructing any original path witnesses.
5. Instantiate the schema on the paper's prefix graphs and distinguish the
   extracted existing theorem from graph-class generalizations. Retain the
   safe-reference premise of that instantiation, without importing subtyping.
6. Falsify proposed stronger statements: independent generators for atoms,
   distinct origins for distinct marks, a singleton-return without its loop,
   unbounded fresh entrances, and unchanged decomposition with inverse edges.
   Prove the bounded-p-entrance correction rather than treating two entrances
   as a general impossibility.
7. Compare actual primary-source contracts for RPQ view rewriting, CRPQ
   containment with inverse, and logical backwards translation. No inference
   of priority from a bounded literature search.

## 1. Graphs, finite tables and the extension operation

Fix finite sets A (emitted letters), D (generator controls) and Gamma (vertex
colours). Fix a Boolean colour test End and the directed labels

    Lambda = {F,S} union {K_a : a in A}.

All these labels are distinct. An admissible base graph is
H=(V,lambda,(E_l)_(l in Lambda)), with lambda:V->Gamma, arbitrary binary edge
relations E_l, and exactly one vertex e satisfying End(lambda(e)). The main
algorithmic application has finite V. Edges need not be functional, total,
acyclic, connected or generated by a word. In particular, no order on V is
part of the vocabulary. Relations are sets of labelled edges, not hidden
nondeterministic choices of a single successor.

A schema T supplies the following finite truth tables/functions:

    Init subset D x Gamma x Gamma;
    Step subset D x Gamma x A x Gamma x D;
    Safe subset D x Gamma;
    rho_a : Gamma -> Gamma                    (a in A);
    chi : D x (A union {END}) x Gamma -> Gamma.

Here END is a new symbol, not a letter or vertex. Require End(rho_a(c))=false
and End(chi(d,n,c)) iff n=END. These two requirements merely keep the output
inside the same unique-End graph class, making iteration possible. Neither
map has to encode states, masks, roots or subtype information. One can omit
these two requirements for a single preimage into a separately specified
output graph class; the proof below still applies.

A legal decorated generator g consists of L>=1, letters a_1,...,a_L,
vertices h_0,...,h_L in V, and controls d_0,...,d_L in D, satisfying

    e E_F h_0;                    Init(d_0,lambda(e),lambda(h_0));
    h_(i-1) E_(K_ai) h_i;        Step(d_(i-1),lambda(h_(i-1)),a_i,lambda(h_i),d_i);
    Safe(d_i,lambda(h_i));        1 <= i <= L;
    h_i != e for 1 <= i < L;     h_L = e.

There is no restriction on h_0 beyond the displayed initialization. The
first-hit condition refers to the positive emitted positions, not the
initial F step. With word-prefix graphs h_0 is the proper-border parent and
is automatically different from e. Empty A or D makes the set of legal
generators empty and the compiled preimage false.

Put n_i=a_(i+1) for i<L and n_L=END. Define H[g] on the disjoint union of
V and genuinely new vertices v_1,...,v_L. Give old x colour
rho_(a_1)(lambda(x)) and v_i colour chi(d_i,n_i,lambda(h_i)). Its entire edge
relation is specified as follows; no unlisted edges are present.

* Keep every old-to-old edge except edges with source e and label S or K_(a_1).
* Add e -S-> v_1 and e -K_(a_1)-> v_1.
* At i<L, add v_i -F-> h_i, and both v_i -S-> v_(i+1) and
  v_i -K_(n_i)-> v_(i+1). For b != n_i, add v_i -K_b-> y for EVERY
  base edge h_i -K_b-> y.
* At v_L, add v_L -F-> e and v_L -K_(a_1)-> v_1. For b != a_1,
  add v_L -K_b-> y for EVERY base edge e -K_b-> y. There is no S edge
  from v_L.

Thus every core-to-fresh edge enters at v_1. Fresh-to-fresh edges advance
by one position, except for the last-to-first wrap. L=1 gives a real wrap
self-loop. Distinct v_i may have the same h_i. The origins are cursors, not
fresh vertex identities. H[g] again has exactly one End vertex, namely v_L.

A generated word alone need not determine H[g]: controls can be chosen
nondeterministically, and in relational bases so can the origin walk. The
existential in the theorem is over ONE decorated generator, and hence ONE
extension, not just separately chosen traces carrying an equal word.

## 2. Observer and query semantics

An observer O is a finite set S_O, initial/final subsets I_O,F_O, a table
Allow_O subset S_O x Gamma, and a transition table

    Move_O subset S_O x Gamma x Lambda x Gamma x S_O.

Path_O(x,y) holds in a graph if there are t>=0, vertices x=x_0,...,x_t=y,
controls s_0,...,s_t and labels l_1,...,l_t, such that s_0 is initial, s_t is
final, every (s_i,lambda(x_i)) is allowed, and every edge x_(i-1) -l_i-> x_i
and corresponding Move tuple exists. Repeated vertices and edges are allowed.
When t=0, x=y and one common control must be initial, final and allow its
vertex colour. No epsilon transition is needed to represent this empty path.

A clause is an existential quantification of finitely many vertex variables
followed by a conjunction of unary finite-colour tests, equalities and path
atoms. We also allow the paper's explicit vertex disequalities. A query is a
finite disjunction of clauses, including the empty disjunction. All atoms in
a clause use ONE assignment to its vertex variables. Path witnesses are
otherwise independent; they have no word registers or required shared
interior history. No inverse navigation, path-label equality, set quantifier
or negated reachability is present.

Strictly, the version with disequality is existential positive over a
vocabulary including the fixed inequality relation. The pure equality-only
existential-positive sublanguage is also preserved below: the construction
introduces no necessary new vertex disequalities. Avoiding End is a finite
colour test, and distinct fresh marks are separated by a positive interval,
not by requiring distinct origins.

For finite graphs, satisfaction is decidable by enumerating vertex assignments
and checking reachability in the finite graph/observer product for each atom.
This is evaluation of a fixed graph, not a word-length search.

## 3. Uniform preimage theorem

**Theorem FR (relational single-entrance first-return preimage).** From the
finite tables of T and a query phi, one can effectively construct a finite
query Pre_T(phi) in exactly the same observer/query language, such that for
EVERY admissible finite base graph H,

    H |= Pre_T(phi)  iff  there exists a legal decorated g with H[g] |= phi.

The compiler has no H, reference word, graph size, extension length, bound on
paths, witness oracle or subtype instance as input. The same formula equivalence
holds on infinite base graphs when path semantics still uses finite walks;
only the finite-graph evaluation claim is then dropped.

The finite-colour maps and exact surgery, rather than any subtype semantics,
are the hypotheses of this theorem. It makes no claim of an optimal hypothesis
characterization among all possible graph transformations.

### 3.1 Bounded diagrams

Fix a clause with v variables and a path atoms, whose observer sizes are
s_1,...,s_a. A zero-state observer makes its clause false and can be discarded.
Put sigma=sum_i s_i and use the conservative finite envelope

    B = 3a + 2 sigma;
    G = 2 + v + 2a + 2 sigma;
    R = v + 2aB.

For each accepted atom, delete a subwalk between any two equal
(vertex,observer-control) configurations until no such pair repeats.
Deletion preserves endpoints, all remaining allow/move tests, and acceptance.
Other atoms impose no condition on this path's removed interior history.
The selected witness visits v_1 at most s_i times. Partition it into maximal
old-core blocks and maximal fresh forward-adjacent blocks, with an edge piece
between successive blocks. Every fresh block after a possible initial one
starts at v_1, by an entrance or wrap. It therefore has at most s_i+1 fresh
blocks and at most s_i+2 core blocks. The total block count is at most B.

Mark v_1,v_L, all fresh values of clause variables, and the two ends of each
fresh block. There are at most G distinct positions. Sort them by their
physical strip order and merge coincidences. At every mark crossed by a
forward block, record that block's observer control, including marks created
by OTHER atoms. Different visits by the same atom retain different entries.

A diagram records: the old/fresh location of every variable; these ordered
mark groups; a control d_t and next value n_t for every group; the first letter
and the base endpoint colour; the first two generator controls d_0,d_1;
core slots; and, for each atom, a list of core, forward, entrance, exit and
wrap pieces. Pieces record endpoints and observer boundary controls; forward
pieces record controls at all crossed marks. The first and last controls are
initial and final. Consecutive pieces share both location and control.

At most R auxiliary old slots suffice: retain old query values and old block
endpoints. At most 2B pieces per atom and BG crossed seam entries suffice.
These loose bounds include the zero-atom case: there are then no pieces or
seams. Enumerate every finite structure within these bounds, every finite
control/colour/letter choice and every compatible variable placement.

Check syntax locally. A forward piece goes from one group to an equal or
later group; in the equal case its boundary controls must agree. Only the
last group has next value END. Entrances use S or K_(a_1), wraps use K_(a_1),
and an exit is F or a mismatching K_b (compare b to n_t at a nonfinal group,
and to a_1 at the final group). Each atom has a nonempty piece list, even
for an empty accepted path. Equalities/disequalities must respect the
old/fresh partition and physical group identity; old/old constraints are
retained rather than guessed from slot names.

This enumeration is deliberately not required to preserve product simplicity.
Simplicity proves COVERAGE of a finite envelope, not a universal bound on the
complexity of every diagram admitted by a concrete enumerator. No C080 U or
F bound is used or asserted.

### 3.2 Compiling a diagram into a base clause

Introduce base variables e,f, one z_t for each group, and the auxiliary core
slots. Require e to have the guessed End colour. Interpret z_t as the group's
origin, not its physical position. Require z_last=e; earlier z_t are non-End.
They may otherwise all alias.

**Core pieces.** Replace each original observer by its slice with the recorded
entering/leaving controls. Evaluate its colour/allow/move tables through
rho_(a_1). Reject an edge when its base source colour is End and its label is
S or K_(a_1). This observer recognizes exactly paths in the induced old core
of H[g]. Pull old variable tests back through rho_(a_1), and keep old/old
equalities and disequalities unchanged.

**Fresh tests.** Pull a test at group t back through
c |-> chi(d_t,n_t,c), and apply it to z_t. Require endpoint allow tests for
every forward piece, including a zero-length one. A zero forward piece uses
one allowed control and no edge.

**Portals.** An entrance forces its old source to equal e. Its Move and allow
tests are unary tests on the first origin, since the endpoint colour, a_1,
and boundary controls are fixed diagram data. A wrap is handled similarly:
its source colour is chi(d_last,END,lambda(e)), and its target colour comes
from the first origin. An F exit forces its old target to equal z_t and
checks the corresponding two mapped colours at that one origin. A mismatch
exit is a base K_b(z_t,y) test, recognized by a two-control observer that
accepts exactly ONE edge, with source colour map chi(d_t,n_t,-) and target
map rho_(a_1). At the final group use the mismatch condition b != a_1.
All original observer boundary allow tests are included.

There is no functionality assumption in this step. Every successful base
mismatch test names an edge copied into H[g]. Different uses may choose
different targets, and all those edges coexist in this ONE extension.
A different semantics that chooses a single successor once per generated
vertex would require global successor consistency and is NOT this theorem.

**First emission.** Require e -F-> f and f -K_(a_1)-> z_0 using exact one-edge
observers. The first checks Init(d_0,lambda(e),lambda(f)); the second checks
Step(d_0,lambda(f),a_1,lambda(z_0),d_1) and Safe(d_1,lambda(z_0)). The shared
first group has control d_1. If there is only one group, z_0=e and this is
already a legal L=1 generator. Otherwise its origin is non-End.

**One synchronous product per physical interval.** For consecutive distinct
groups t,t+1, take all forward traversals crossing that interval. Each
traversal contributes its own observer coordinate, even if another coordinate
comes from the SAME atom or another traversal of the SAME edges. Let there
be ell such coordinates, with observers O_1,...,O_ell.

Build an observer on the base graph with controls

    (d,n,seen,p_1,...,p_ell),

where d is in D, n is a letter or END, seen is Boolean, and p_j is in S_(O_j).
It has at most 2|D|(|A|+1) product_j |S_(O_j)| controls. At a vertex of base
colour c it requires Safe(d,c), (n=END iff End(c)), and all original observers
to allow the one colour chi(d,n,c). Its transitions consume only base K_a
edges, with n=a and source non-End. Across a base edge c -K_a-> c', choose
d',n' satisfying Step(d,c,a,c',d'), Safe(d',c') and
(n'=END iff End(c')). For each j choose an allowed O_j transition labelled
S or K_a, from chi(d,n,c) to chi(d',n',c'). Every coordinate sees the SAME
letter, origin edge and two produced colours. Set seen'=true.

The initial tuple is the shared left boundary data, with seen=false, and the
final tuple the shared right boundary data, with seen=true. The recorded
seam controls specify each p_j at both ends. This enforces positive length
even when z_t=z_(t+1). END has no outgoing generator step, excluding a hidden
earlier return. Retain this observer when ell=0: an unobserved interval must
still be generated. Adjacent interval tuples share d,n and their origin
variable, so the next-letter lookahead cannot disagree across a seam.

Conjoin all these base tests, equalities, portals, core paths, first-emission
atoms and interval atoms. Existentially quantify all base variables. Disjoin
over valid diagrams and input clauses. All tables have finite domains and
are explicitly enumerable. Every newly introduced path atom is an observer
of the ORIGINAL language. In particular, no predicate secretly runs a graph
algorithm or looks up an unbounded numerical position.

### 3.3 Coverage

Assume one legal g gives H[g] |= phi. Choose a satisfied clause, its one
vertex assignment, and product-simple accepting paths for all atoms.
Section 3.1 extracts a diagram in the finite envelope. Interpret its marks
at their actual physical positions, its z_t at their actual origins, its
core slots at actual old vertices, and all finite guesses by the actual
controls, colours and letters of g. Coincident physical roles are merged;
coincident origins of different positions are not merged.

Exact surgery gives the pulled-back core witnesses and every portal test.
All equalities and disequalities follow from the chosen one assignment.
Restrict g to each consecutive marked interval. Pair this SAME restriction
with the runs of all traversals crossing that interval, splitting them at
all global marks. These runs yield an accepting product path. Positive
interval lengths and first-hit guards follow from g. Empty forward pieces
supply their single allowed control. The first emission satisfies its two
edge tests. Hence one enumerated compiled clause is satisfied in H.

### 3.4 Reconstruction

Assume H satisfies one compiled clause and fix its base assignment. Choose
a witnessing path for each interval atom and the first-emission atoms.
Reading the generator coordinates gives a base walk with controls and emitted
letters. Concatenate these walks in physical interval order. Their shared
origins, controls and next-letter values match. The first two edge atoms
provide e -F-> h_0 and the first emission. Positivity separates consecutive
physical groups; all intermediate origins are non-End, and no interval can
leave End. The last origin is e. Thus the concatenation is ONE legal
decorated generator g. For one group the first emission alone defines it.

Construct H[g] once, before reconstructing any original path. Put fresh
query variables at their prescribed physical groups and old variables at
their base values. Since groups are physically distinct exactly when their
indices differ, the retained equality/disequality requirements hold; equal
origins cannot collapse new vertices. Their colour tests hold by the maps.

Each product coordinate now gives its forward observer segment on this same
strip. Join segments at the recorded seam controls to recover every forward
piece. Core witnesses lift along the exact core recolouring/deletion rule.
Every portal is an edge of H[g], by its local test and the relational-copy
rule. Join the pieces at their matching locations and controls. This gives
an accepted path for every original atom on this one H[g]. A zero piece is
an allowed reflexive run; a singleton wrap is the specified self-loop, not
an empty run. The original clause, and hence phi, holds. This proves FR.

All witnessing paths used here are finite even if V is infinite. The diagram
envelope and compiler are graph-independent, proving the infinite-base
semantic extension too. No decidability claim for presenting or evaluating
an arbitrary infinite graph follows. QED.

## 4. Instantiating the current prefix-graph construction

For an arbitrary finite binary automaton I with controls Q, transition
function delta, final set Fin, ordered flags G_I and Bad states, take

    A={0,1};  D=Q;
    Gamma=Q x 2^Q x {0,1,END} x {false,true}^2.

End is the last component. Use the paper's rho_a=core_a and
chi(q,n,c)=(q,col(q) union c.mask,n,false,[n=END]). Put

    Init(q,c_e,c_f) iff q=c_e.state;
    Step(q,c,a,c',q') iff delta(q',a)=q;
    Safe(q,c) iff q notin Bad, (q,q) notin G_I, q notin c.mask.

Let B be a NONEMPTY safe labelled reference as in manuscript Section 5.
Its graph has vertices 0,...,m; failure F(j)=pi(j), successor S(j)=j+1 for
j<m, and K_a(j) the longest prefix of B which is a suffix of B[:j]a.
Colours contain the old label, the union of incoming flag columns at all
border lengths (empty and full included), next symbol, root bit and End bit.
The unique End vertex is m. Its S edge is absent, so the generalized core
suppression of S has no additional effect. The above schema's h_0 is pi(m).

Here is the graph-to-word identification needed for the instantiation.
Before the first new occurrence of B, no fresh prefix can have a proper
border of length at least m: a border of length m is a return, and a longer
one contains an earlier completed copy of B. At the first return the longest
proper border is exactly m, because the same argument excludes a longer one.
Consequently the fresh proper-border parent is the cursor h_i. Every proper
border of a word is a border of its longest proper border, so its full mask
is col(q_i) union M_(h_i). Thus Safe is precisely the new-position safety
check, including diagonal flags and the empty-border contribution inherited
in M_(h_i). The reverse transition is precisely Step. Matching letters advance
the fresh strip; mismatches fall back to h_i and use its old K edge. At the
new endpoint fallback is m, whose matching first-letter edge enters v_1.
Old proper prefixes cannot point into a longer fresh prefix. These observations
prove both directions of the generator/surgery identification, including
old-label preservation, overlapping returns and L=1.

Therefore FR specializes to manuscript Theorem 7.1 and the semantic conclusion
of `RankQueryCoverage.closure_iff`. This specialization is an EXTRACTION of an
existing result, not a new proof-status promotion or publication-priority claim.

The following distinctions are essential.

| Hypothesis/data | Role and status |
|---|---|
| Arbitrary-tree subtype semantics, canonical models, normalization, summary-instance provenance | Not used in FR or the prefix-graph specialization. These connect the graph theorem to the separate entailment problem. |
| Terminal finals, absorption, border-rank bound | Not used locally. Terminality bounds the number of promotions in the later decision; absorption supports the terminal/cyclic split. |
| Ordered flags, Bad, reverse transitions, border masks | Arbitrary finite local data in the word instantiation; no flag symmetry, empty Bad set, restricted initial state or subtype-realizability assumption is needed. FR replaces them by finite tables. |
| Safe old reference and preservation of old labels | Retained when the right-hand side means a globally safe word extension. FR only checks new emitted positions; it does not retroactively certify the old reference. |
| First return of B | Justifies the exact strip surgery for literal prefix graphs. It is not interchangeable with an arbitrary later return. |
| Binary alphabet, functional base edges, KMP/base-word representation, root bit | Not needed in FR. Finite alphabets and relational edges are covered by its explicit construction. A colour-definable endpoint and local maps remain. |
| Finite base graph | Needed for the stated finite evaluation algorithm, not for the formula equivalence with finite-walk semantics. |
| One entrance and forward fresh interior | Supply the block bound; the bounded-portal correction below is weaker. |
| Finite-state observers and finite tables; single shared extension | Used directly in the proof and retained. No arbitrary registers or independent generators are admitted. |

A concrete reason not to erase the old-safety premise: with empty flags and
Bad={bad}, take B=00 with labels (f,bad,p) and transitions
bad -0-> f, p -0-> bad, q -0-> p, with f final. The local first emission
0 with fresh state q passes Safe at origin m, since the mask is empty and
q is not Bad. Nevertheless C=000 still contains the old bad-labelled position,
so is not globally safe. FR correctly describes a local graph extension;
identifying it with a safe word extension on this B would be false.

## 5. Precisely what additional entrances and inverse edges change

**Bounded-portal lemma.** Suppose a strip extension instead has a set P of at
most p designated fresh vertices. Every core-to-fresh edge and every
non-forward-adjacent fresh-to-fresh edge must land in P. All other fresh
interior edges are forward adjacent. For an s-control product-simple path,
there are at most ps+1 fresh blocks and ps+2 core blocks.

*Proof.* Every block except a possible initial fresh block starts at a vertex
of P. The path has at most ps visits to P because every (vertex,control) pair
is distinct. Core blocks can only be separated by fresh blocks. QED.

For a conjunction, B_p=3a+2p sigma and
G_p=2+p+v+2a+2p sigma are safe envelopes after also marking P. In particular,
a fixed second entrance does NOT preclude a uniform finite decomposition.

Here p counts ALL portal targets, including v_1 when the usual entrance/wrap
edges are present. A same-language extension of FR follows under an explicit
additional interface condition: these at-most-p portal positions are selected on the ONE generated strip,
and every additional portal-edge predicate has a fixed finite definition in
the base query language on its marked origins/core endpoints, with finite
control/next/colour data as parameters. The core rewrite and generator remain
as in Section 1. An edge exists exactly when its defining predicate holds;
there are no hidden once-only choices of its target. Then include the p roles
in the global marks, use B_p,G_p, and substitute those fixed base predicates
for portal tests. Coverage takes the actual portal positions and the edge
predicate witnesses. Reconstruction chooses all those witnesses on H and
builds the single extension, whose exact edge predicates supply every chosen
portal edge. Interval products and equality handling are unchanged. Finite
disjunctions are distributed, and auxiliary variables are freshly renamed.
This proves the bounded-p corollary without assuming arbitrary attachments
are definable or equating independently generated words.

**Two entrances already refute the OLD one-entrance numerical bound.** Take
fresh v_1,v_2,v_3, old c_0,c_1, the usual forward fresh S edges, and edges

    v_3 -F-> c_0 -J-> v_1 -F-> c_1 -J-> v_2.

There are two entrance targets {v_1,v_2}. A one-control observer admitting only
F,J has a unique accepting walk from v_3 to v_2. It is product-simple and has
three fresh blocks, exceeding s+1=2. It respects ps+1=3. This example uses an
extra directed portal label J, not the inverse of an edge.

**Unbounded entrances defeat every bound depending only on observer size.**
For N>=1, take old c_0,...,c_N and fresh v_1,...,v_N, with all fresh forward
S edges and c_(i-1) -J-> v_i -F-> c_i. The fixed two-control observer (JF)*
from c_0 to c_N has a unique accepting walk, with N fresh blocks and no
repeated product configuration. N is arbitrary. This refutes the uniform
block bound after dropping a uniform entrance bound. It does NOT prove
non-definability of preimages or undecidability for the enlarged class.

**Inverse S defeats the forward-block argument even without core excursions.**
On a directed S-chain v_1,...,v_L, L>=2, supply Sbar as the inverse of S.
A fixed four-control observer for (S S Sbar)* S, from v_1 to v_L, must take
L-2 three-edge iterations followed by S. It makes L-2 backward moves. After
iteration i its position is 1+i; its intermediate controls occur at positions
2+i and 3+i. Thus no (vertex,control) repeats. These arbitrarily many direction
changes survive product-cycle deletion. The directed forward-piece envelope
cannot be retained unchanged. For L sufficiently large even the count of
maximal forward pieces exceeds the old s+1 bound.

An inverse F is another problem: if many fresh origins coincide at h, the
inverse relation supplies edges from h into all those different fresh
positions. It creates unboundedly many fresh entrance targets. Neither example
rules out a DIFFERENT two-way/crossing-sequence or logical preimage method.

**First-return surgery cannot just be asserted for later returns.** For B=0
and C=000, the longest proper border of the final prefix has length 2>m.
The final F edge is 3->2, whereas the first-return rule would incorrectly
make it 3->1. The first return already occurred at 00. This is a direct
counterexample to extending the prefix-graph surgery unchanged.

## 6. Positive and negative regression specifications

The independent program accompanies this note. Its concrete prefix graphs
are defined by literal prefix/suffix equality, not imported KMP/compiler code.
The following conclusions have separate all-length arguments; bounded
execution is supplementary evidence.

**One conjunction, one extension.** Without local restrictions, first-return
extensions of B=0 are exactly 0 1^n 0 for n>=0. A query from Root to End
requiring S-length 2 has witness 00, and S-length 3 has witness 010. Their
conjunction has none, since the S-chain has one fixed length. Thus
Pre(phi AND psi) need not equal Pre(phi) AND Pre(psi).

**Repeated traversal.** In B=0,C=010, fresh vertices v_1=2,v_2=3 have a forward
S edge and a K_1 wrap. The observer S K_1 S from v_1 to v_2 crosses the SAME
physical interval twice, with different boundary controls. Its product must
retain two coordinates. Requiring only one coordinate can reject this valid
query or conflate the runs.

**Origin aliases and positive intervals.** In B=0,C=0110 the first two fresh
positions both have origin 0. They are distinct physical vertices separated
by one generator K_1 self-loop at 0. Forbidding equal origins loses this
extension and queries distinguishing those two positions. Conversely allowing
an empty interval for distinct marks can falsely realize x!=y at one position.

**Singleton, overlap and empty path.** B=0,C=00 has one fresh vertex whose
K_0 wrap is a self-loop and whose F edge reaches the old endpoint. The return
overlaps. A query can simultaneously require this edge, an empty path at its
vertex, and equality of variables carrying different roles. B=00,C=000 gives
another single-emission overlapping return. An empty path remains false when
its only control disallows the vertex colour.

**Relational exits.** On base {r,e}, e End, put e -F-> r,
r -K_0-> {r,e} and e -K_1-> {r,e}. A one-emission generator 0 can choose e,
producing a singleton fresh v. Both v -K_1-> r and v -K_1-> e exist. A clause
requiring these exits to distinct old targets is true on ONE extension.
This is outside functional Graph but inside FR. Replacing this edge set by
an independently re-chosen single edge per atom would not be an adequate
semantics for a functional variant.

**End guard.** A generator segment hitting End and then leaving it must be
rejected, even when it later reaches End again. Positive-length enforcement
must distinguish two physical groups whose origins coincide. Unobserved
intervals cannot be discarded.

## 7. Exact bounded comparison with prior graph-query results

These primary sources were read for their actual definitions and statements;
none is used as an unproved black box in FR. This is a contract comparison,
not a proof that no encoding or more general theorem could subsume FR.

* Calvanese, De Giacomo, Lenzerini and Vardi, **Rewriting of Regular Expressions
  and Regular Path Queries**, PODS 1999, Definition 6 and Theorem 10 (p. 200),
  Theorems 2-3 (p. 196). They characterize sound/exact view rewriting by regular
  language substitution and compute a maximal rewriting. The quantification
  is over all databases and expansions of view symbols. FR instead existentially
  chooses one generated graph extension and eliminates a whole conjunction.
  The theorem is not an immediate instance of that view-substitution contract.
  Source: https://www.inf.unibz.it/~calvanese/papers/calv-degi-lenz-vard-PODS-99.pdf

* The same authors, **Containment of Conjunctive Regular Path Queries with
  Inverse**, KR 2000, Section 2, Theorems 2, 4-6 and Section 4.1 (pp. 178-182).
  They handle shared variable assignments, canonical counterexample graphs
  and two-way automata; containment is EXPSPACE-complete. Their annotation
  projection explicitly requires consistent guesses on revisiting a position.
  Thus shared-position consistency and automata products are established
  methodology, not claimed innovations here. The output is a containment
  decision construction, not FR's same-language query on each supplied base.
  The inverse-edge examples above do not contradict their two-way method.
  Source: https://www.inf.unibz.it/~calvanese/papers/calv-degi-lenz-vard-KR-2000.pdf

* Courcelle, **On first-order definable operations on relational structures**,
  arXiv:2605.31260v1, Definitions 1.3 and 4.1, Theorem 2.3, Corollary 2.4,
  and Section 4.1, recalls the backwards-translation framework and its relation
  to Courcelle-Engelfriet's 2012 Theorem 7.10. The inspected copying definitions
  bound output domains by V x [k] (or V^k for the stated vectorial variant).
  FR allows arbitrarily long strips over one fixed two-vertex base (B=0 above),
  so this exact extension relation is not such a fixed-copying transduction.
  Logical inverse-image closure also does not by itself give FR's restricted
  observer syntax. An indirect encoding or query-dependent bounded surrogate
  is not excluded. This 2026 source is a preprint/survey; the entire 2012 book
  theorem was not independently retrieved here.
  Source: https://arxiv.org/html/2605.31260v1

The paper's existing Section 7.1 result and its checked prefix-graph compiler
are prior project results. The new contribution in this note is their explicit
relational finite-table extraction/generalization, the bounded-p correction,
and the precisely scoped obstruction families. No publication priority,
complexity improvement or new subtype decision theorem is asserted. The
literature search is bounded to these close graph-query/backwards-translation
contracts, not an exhaustive survey of all graph transductions or grammars.
