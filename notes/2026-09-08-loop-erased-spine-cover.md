# Exact finite loop-erased spine cover

Date: 2026-09-08. Workstream A017, supporting A012/A016.

**Status:** elementary written proof + executable decomposition/regression. Not Lean-checked. This is a representation theorem, not by itself a solution of Problem 1.7.

## 1. Statement

Work in one finite safe terminal candidate automaton `J=(Q,delta,s,F)` over a finite alphabet. For a state `q`, let

    Ret(q) = { u : delta(q,u)=q }

be its regular return language, including epsilon.

A **simple labelled accepting spine** is a path

    q0=s --a0--> q1 --a1--> ... --a_(r-1)--> qr in F

whose states are pairwise distinct. There are finitely many such spines and `r<|Q|`.

To one spine associate the regular-constrained word template

    Ret(q0) a0 Ret(q1) a1 ... a_(r-1) Ret(qr).       (S)

In a terminal-final slice `Ret(qr)={epsilon}`, but keeping it in the notation is harmless.

**Theorem 1 (exact spine cover).** The accepted candidate language is exactly the finite union of (S) over all simple labelled accepting spines.

This is stronger than merely saying that every regular language has a regular expression: the recurrent pieces are explicit literal word variables whose values remain available for later shared-word/suffix reasoning.

## 2. Last-occurrence proof

Take any accepted word `w=a_0...a_(n-1)` with run states

    c0,c1,...,cn,    c0=s, cn in F.

Start at position `t0=0` and state `q0=c0`. Let `ell0` be the LAST index at or after `t0` with `c_(ell0)=q0`. The factor

    M0 = w[t0:ell0]

therefore belongs to `Ret(q0)`. If `ell0=n`, we are done. Otherwise let the next literal edge be

    b0 = w[ell0],    q1=c_(ell0+1),

and repeat from position `t1=ell0+1`.

At every stage `h`, choose `ell_h` as the last occurrence of the current state `q_h` in the remaining run, record the closed factor `M_h`, then take the next single edge if the word has not ended.

The resulting spine states are pairwise distinct. Once we leave `q_h` after its last occurrence in the whole remaining run, `q_h` can never be selected again later. The process terminates at `c_n in F` and factors the original word exactly as

    M0 b0 M1 b1 ... M_r.

Hence every accepted word lies in the template of one simple accepting spine.

Conversely, choose arbitrary `M_h in Ret(q_h)` in one spine template. Reading `M_h` returns to `q_h`, then the literal edge `b_h` advances to `q_(h+1)`. Induction follows the spine to an accepting state. Thus every word generated by the template is accepted. QED.

## 3. Why this matters for A017

The unrestricted recurrence problem can now be restated without guessing a run-count bound.

For each of finitely many spines there are at most `k` recurrent word variables

    X_h in Ret(q_h),

and each variable has one physical occurrence in the candidate expression. Arbitrarily many concrete loop traversals, nested excursions, and nonflat SCC behaviour are absorbed into these regular return languages. Literal identity of `X_h` is NOT quotiented to a transition action.

Therefore a complete terminal solver may work spine by spine. The remaining difficulty is exactly the comparison relation induced by flags across the concatenation

    X0 a0 X1 a1 ... Xr.

A violation can start/end inside variables and can compare different offsets of the same or different return words. This is still nonregular shared-word structure, so Theorem 1 alone does not imply decidability.

The representation does, however, eliminate one source of apparent infinitude: there is never a need for an unbounded NUMBER of explicit recurrent variables. Their number is at most the number of states. What is unbounded is the literal content of finitely many regular variables and the synchronized suffix obligations between them.

This distinction is important relative to earlier run/marker-count work. Superpolynomially many concrete runs can be encoded inside one `Ret(q)` variable; a failure to bound runs does not contradict the finite spine cover.

## 4. Relation to the generic PCP warning

The repository already records that unconstrained iteration of shared two-output templates can encode PCP. The spine cover does not invoke arbitrary template iteration. It yields a straight-line candidate expression in which each return variable has one physical occurrence and a fixed regular language.

This does NOT prove that the resulting system of multiple suffix-avoidance constraints is decidable. The 2025 negated-containment theorem handles one `not-contains` predicate with arbitrary regular variable languages, while its published future-work section explicitly leaves multiple such predicates open. The spine restriction is therefore a concrete structural property to exploit, not a license to cite that theorem as a solution.

## 5. Immediate algorithmic consequences

Several branch results fit naturally on top of the spine cover:

* `common_suffix_selector.py` proves NO when a flagged comparison lies wholly in a forced literal tail independent of all return variables.
* the bounded-exposure theorem handles a return variable lying between source and target when the selected comparison sees only a bounded prefix of that variable's insertion.
* fixed choices `X_h=epsilon` give the literal spine word itself. Hence if any simple spine word is a witness, the original instance is immediately YES.
* for a NO instance every simple spine word is bad. The problem is to lift at least one of its violations uniformly over all assignments to the `Ret(q_h)` variables.

The last bullet suggests a finite search over spine violations plus a finite catalogue of interaction types with return variables. The hard types are those where source and target both consume unbounded portions of return variables at different offsets.

## 6. Executable evidence

`experiments/loop_erased_spines.py` implements the last-occurrence decomposition and simple-spine enumeration. `check_loop_erased_spines.py` verifies reconstruction/return-state facts on:

* all 32,767 binary words through length 14 for the six-state barrier automaton; all 262 accepted words decompose into one of its two simple accepting spines;
* 672 structured nonflat candidates with two recurrent middle blocks; and
* all 81 two-state partial binary transition tables, checking 1,400 accepted words through length six.

These finite tests validate the implementation only; Theorem 1 is the all-length argument.
