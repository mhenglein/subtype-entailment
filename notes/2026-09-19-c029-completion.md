## Exact result and boundary

The result is the total Boolean `InfiniteDecision.infiniteWitnessCheck` with

```lean
infiniteWitnessCheck_correct (I : Instance k) (hA : Absorbing I) :
  infiniteWitnessCheck I = true ↔ AbsorbingTerminal.InfWitness I
```

Here `Absorbing` is the existing strong condition: every defined successor of
an original final control is final and its entire incoming flag column is
empty. `InfWitness` is the existing proposition containing an original finite
`Basic.Witness` and an explicit safe stem followed by a nonempty safe cycle.
No definition of Witness, flags, safety, absorption or continuation is changed.

The result includes arbitrary pre-final loops, partial transitions, Bad
controls, ordered flags, diagonal cuts and the empty prefix. A false answer
excludes only infinitely continuable witnesses; terminal witnesses remain
possible. This is C029, not the final expression-level Problem 1.7 theorem.

## Finite monitor construction

Fix a nonempty word c of length d and a candidate cycle base q. A monitor state
contains a control in `Fin k`, a phase in `Fin d`, a Boolean matching flag, and
a length-d vector of k Boolean bucket entries. Every such state is explicitly
enumerable. There are at most `k*d*2*(2^k)^d` states, including unreachable and
inconsistent combinations. The proof uses that full finite carrier.

The seed has current control q, phase zero, matching=true, and only q in the
phase-zero bucket. `prefixCheck` explicitly requires q to be safe. A reverse
edge chooses a predecessor p and a Boolean letter a, requires p to be safe
and `step I p a = some current`, and performs these operations:

- In a matching state, decrement the phase. If a differs from the cycle
  letter at that phase, enter a nonmatching state with reset buckets.
- If a matches, compare its rotation with every bucket's rotation. Reject
  when a stored target r has the ordered flag `(p,r)` and an equal rotation.
  Otherwise add p to the new phase bucket, retaining old members.
- A nonmatching state remains nonmatching. Its phase and buckets are reset;
  their values have no semantic meaning in this branch.

The successor list enumerates every predecessor and both letters. An accepting
state has current control equal to the original initial control. A labelled
path stores each reverse edge by prepending its letter. Thus its accumulated
word runs forwards from the current control to q.

`phaseEqual` compares all d letters of two rotations, not their phase numbers.
Distinct phases of a nonprimitive period may denote the same ray. The phase
bridge proves finite rotation equality iff equality at every infinite offset.

## Why both language directions hold

The periodic reference is aligned with phase zero at the end of the supplied
prefix. `Matches` says the whole prefixed stream equals this reference. The
existing eventual-period lemma proves that equality of two distinct suffixes
starting at cut zero requires Matches. Prepending preserves failure of Matches.

The forward invariant carries SafeRun and GoodFrom for the whole accumulated
word. In a matching state it also carries the exact aligned phase, Matches,
and membership of every genuine cut control in its phase bucket. In a
nonmatching state it carries `not Matches`. The GoodFrom prepend recurrence
preserves every old comparison. Its only new obligations start at cut zero.
For a matching prepend, bucket membership and `hasConflict=false` discharge
those directed flags. For a nonmatching prepend, the periodic suffix criterion
rules out those new equal suffixes. A left mismatch never repairs an already
rejected comparison between later cuts.

Completeness uses a separate `BucketSound` carrier: every stored member has a
real cut, exact phase and actual control. This prevents a spurious member from
blocking a good prefix. `matching_member_iff` retains all old members and adds
exactly the new source cut. `good_no_conflict` obtains a concrete forbidden
comparison from any supposed conflict and contradicts GoodFrom. Induction on
the word then constructs a labelled path for every safe good prefix. This
converse does not need a false-state semantic carrier; forward soundness
provides that separately.

The empty prefix uses the seed; its strict ordered comparison predicate is
vacuous. SafeRun still checks its sole cut, including the diagonal flag. All
comparisons preserve `(earlier source,later target)` order.

## Finite search and executability

`FiniteSearch` maintains a duplicate-free visited list. Each round either is
a fixed point or increases its length. A complete list of states therefore
bounds the rounds needed for all reachable states. `reachesAnyWithFuel`
accepts a numeric upper bound on the carrier's size and stops early at a fixed
point; the complete list is used only in its proof. C029 computes the numeric
bound rather than materializing the whole raw carrier before searching.

The executable definitions use no classical choice. Classical reasoning in
erased propositions does not supply runtime search. The correctness theorem
has only the explicit Absorbing hypothesis: no monitor, trace, bound or
reduction premise remains.
