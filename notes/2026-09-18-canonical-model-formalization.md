## 1. Target and remaining route

A total end-to-end subtype algorithm needs a semantic specification over ALL
possibly infinite trees, an exact finite construction interpreting normalized
constraints, a correct terminal decision, and a correct composition. The
preceding support note identified these contracts; this work formalizes the
first semantic equivalence rather than duplicating that audit.

The main result is `CanonicalModel.not_entails_iff_canonical`:

    not Entails(C, alpha, beta)
      iff exists finite pi,
        closure(forced roots + every alpha-prefix of pi) avoids denials
        and that closure does not contain (beta, pi).

All finite normalized constraint systems are covered, including inconsistent
ones. The existence on the right is NOT supplied by a witness bound, a finite
model assumption or a decision oracle. This theorem does not make the right
side effectively decidable. Effective Pop/Post saturation, construction of I_C,
absorption, C029/C031 and the terminal decider remain separate Lean obligations.
Input normalization from compound surface expressions is not implemented here.

## 2. Representing arbitrary trees without adding a restriction

`TreeSemantics.Tree` stores a predicate `Word -> Prop` and a proof of prefix
closure. Word is the existing `Subtail.Word = List Bool`. No decidable-membership,
finite-set or regular-automaton field is required. The finite index type `Fin n`
restricts the input variable names, NOT the depth or regularity of their trees.

Product addresses satisfy the literal equations

    bottom.nodes(w) = False;
    product(X,Y).nodes([]) = True;
    product(X,Y).nodes(false :: w) = X.nodes(w);
    product(X,Y).nodes(true :: w) = Y.nodes(w).

Subtyping is `Below`, inclusion of those predicates. `product_mono` proves
covariance. This follows the reviewed product-address semantics; it is not
an independent reread of the original memo or a new coinductive order theorem.

A separate `TreeDiagram` specification has a defined-address predicate and a
product-address predicate. The root must be defined, every product is defined,
and a child is defined exactly when its parent is a product. Bottom is the
remaining defined, nonproduct case. The functions `toDiagram` / `ofDiagram`
show that these data carry the same product set and exactly the same domain.
`diagram_domain_exact` checks the nontrivial domain direction. `tree_roundtrip`
checks the path-set round trip. In particular the empty product set still
has a bottom ROOT and no children; there are no disconnected extra nodes.

The infinite `zeroSpine` is defined directly as words whose letters are all
false. It is a semantic predicate, not an enumerated approximation.

## 3. The normalized constraints and inductive closure

`Constraint` has exactly four constructors: leq, upper product, lower product,
and denial. `Holds`, `Models`, `Satisfiable` and `Entails` quantify over the Tree
valuations just described. No terminal automaton or rank assumption is used
in this semantic layer.

`Derived C S q w` is generated by finite derivations using seed, variable
inclusion, left/right pop for upper products, and left/right push for lower
products. Stack symbols are prepended on the LEFT, matching the prior bridge.
There is no prefix-closure inference rule whose addition could silently change
the reachability problem. Prefix closure is PROVED from the seeds instead.

Two sufficient seed contracts are explicit:

* each variable's seeds are prefix closed;
* every target of a lower product has its empty-address seed.

`derived_take` proves that every finite prefix of a derived address is derived.
The decisive push case at prefix length zero uses the forced-root seed. Pop
cases use the old derivation's prefix one symbol longer. Therefore
`closureValuation` is a genuine arbitrary-tree valuation, not a collection of
unrelated membership facts.

`derived_sound` places every finite derivation in every model containing its
seeds. `closure_models` verifies each of the four normalized clause forms when
no denied fact is derived. Together with `avoids_of_model`, this gives
`closure_models_iff`: the complete closure is a model iff it avoids denials.

## 4. Canonical satisfiability and separating addresses

For satisfiability use only the forced-root seed set. These seeds are contained
in every model. If their closure avoids denials, that very closure is a model;
if a model exists, it contains the closure, so no denied fact is derived.
This proves `satisfiable_iff_forced_safe`. It is an equivalence of propositions,
NOT a Boolean satisfiability checker or a classical executable branch.

For a proposed address pi, `pathSeeds` adds ALL prefixes of pi at alpha, not
just pi itself. The canonical closure contains (alpha,pi) and is below every
model containing that fact. A countermodel supplies a finite address in the
failed inclusion, even when its trees are infinite. Conversely, a safe closure
missing (beta,pi) is itself a countermodel. These are the two directions of
`not_entails_iff_canonical`.

There is no explicit SAT premise in this final declaration because the right
side includes safety of the ENTIRE forced-root plus prefix closure. This does
not authorize dropping the SAT guard when later optimizations split safety
into separate summary conditions. Those optimized contracts remain unchanged.

Classical reasoning extracts a finite separating address from a failed
universal inclusion; it lives in erased proof terms. It is not an algorithm
that computes a counterexample from an arbitrary predicate-valued valuation.

## 5. All-length semantic regression proofs

`CanonicalModelAudit.lean` proves the following fixtures using these definitions:

1. `spineConstraints = [lower 0 1 0, denial 1]` has the concrete model
   X(0)=0*, X(1)=empty and fails query 0<=1 at the empty address.
   EVERY model of these constraints contains all 0^i. Thus no model has a
   bounded product depth; a finite-model replacement is invalid.
2. A lower-product target that is denied makes the system unsatisfiable;
   every queried inequality then holds vacuously.
3. An empty prefix seed has a required nonempty consequence through a lower
   product. The one-word-only seed set is not prefix closed.
4. The bottom root exists and has no children.

These are quantified Lean proofs, not a bounded Python sample. They protect
semantic boundary cases but do not prove a new global algorithm.

## 6. Non-interference and validation design

Only new modules and a separate read-only workflow are added. Existing
`Subtail.Basic`, rank/query modules, the toolchain, existing workflows and
`lean/Subtail.lean` are unmodified. The workflow explicitly builds and replays
`Subtail.CanonicalModelAudit`, so these new modules are not silently missed
because the shared aggregator has not yet been updated.

The dependency audit enumerates all named public definitions, inductive types,
structures, abbreviations and theorems in the three modules. It requires a
matching axiom report for each. Only the repository's standard `propext` and
`Quot.sound` are allowed, with `Classical.choice` additionally allowed for proof
theorems. No custom research axiom, `sorryAx` or native-evaluation axiom is allowed.
The checker then runs the earlier complete Lean-core test script and requires
its tracked result to stay unchanged.

The proofs were written and semantically read back by this same assistant.
Kernel replay uses Lean's own kernel, not an independent implementation or a
human mathematical referee. Source-memo fidelity is inherited from the previous
ordinary semantic review; this turn does not claim a fresh original-PDF audit.
