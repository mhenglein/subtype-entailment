## Exact finish line

Use a finite encoding of a constraint set C and query variables alpha, beta. Define a total executable function returning true exactly when every valuation satisfying C also satisfies alpha <= beta. If C is unsatisfiable, the answer is true.

The intended interface is schematic, not compiled Lean code:

```text
decideEntailment : SEPInput -> Bool
decideEntailment_correct :
  forall i, decideEntailment i = true <-> Entails i
```

Entails must quantify over the memo's arbitrary, possibly infinite trees with bottom and covariant binary product. A proposed representation is a prefix-closed set of finite binary product-node paths. It must allow arbitrary sets, without requiring decidable membership or a finite-state presentation. Prove its correspondence with the memo's tree definition and constructors; see [C001](../claims.md#c001).

Regular infinite countermodels may be used only through a proved reduction. Finite-tree entailment is a different problem. Normalization must preserve the original query, including the treatment of any fresh variables.

A proof that some Boolean-valued function exists, or an arbitrary Decidable instance, is insufficient. The delivered definition must compute on finite encodings and have checked termination and correctness.

The forward dependency chain is:

**Executable budget bound → complete finite search → BorderAvoid decision procedure → subtype decision procedure.**

O5 can first be proved against a named interface for O4. Its statement must expose the Boolean test and its soundness/completeness assumptions until O4 is implemented. The same discipline applies to the later reduction interfaces. Parameterized proofs establish exactly those conditional statements.

O4 must connect reverse state annotations to a real DFA run. Require c'(n)=q0, c'(0) in Fin, all reversed transitions valid, and all visited states outside Bad. Border checks alone do not enforce these conditions.

O7 must handle the satisfiability premise of Theorem 2.6 constructively. Use an executable satisfiability procedure or prove a reduction that handles unsatisfiable inputs directly. A classical branch on Satisfiable C would leave the final algorithm noncomputable.

### The bound contract

Use an effective finite encoding and specify size(I) as code length, including alphabet, states, transition table, flags, and side conditions. Fix the binary alphabet where appropriate for SEP; abstract BorderAvoid may use other finite alphabets. Formalizing the reverse direction of Theorem 8.9 would additionally require effective enumeration of the finitely many codes of each size; it is outside the initial core.

The bound is an executable function F from natural numbers to natural numbers. Its required coverage hypothesis is:

```text
For every well-formed instance I:
  if some word satisfies Witness(I),
  then there exist L,D with L+D <= F(size(I))
  such that S''_I(L,D) is nonempty.
```

Avoid defining a least successful B(I) on instances without witnesses. The existential contract above states exactly what the decision argument needs. It does not require every witness to satisfy the bound, and it assumes no monotonicity of F.

Enumerate all pairs L,D within F(size(I)) and decide each S-automaton's nonemptiness by complete finite graph search. Soundness turns a successful search into a witness. Coverage turns failure at every enumerated pair into nonexistence. The graph-search termination proof must supply an explicit finite state space.

The numeric bound is on L+D, not word length. A separate automaton argument is required to derive a word-length bound if one is used. Searching words only up to F(size(I)) would be a different and unjustified algorithm.

A theorem parameterized by an arbitrary F remains conditional. Before claiming an executable solution, provide a concrete computable definition of F and discharge its coverage proof, or provide an explicit program computing F with a totality proof. Classical existence of a function does not supply this program. A bound proved only for subtype-derived instances can be enough for O7, but must not be advertised as deciding arbitrary BorderAvoid.
