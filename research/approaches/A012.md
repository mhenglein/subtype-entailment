### 2026-09-08 - Orbit/residue and bi-residue arithmetic cut selectors

Recorded by ChatGPT after the regular-decoration barrier. This continuation
changes proof shape rather than adding marker memory: it partitions an infinite
regular candidate language into arithmetic cells and selects an explicit
violating cut in each cell.

The installed three-way rule for `a^n b M a^m b a` was first repaired at its
automatic-synthesis boundary. Choosing the maximal set of tail-capable middle
endpoints can introduce unnecessary decompositions and hence unnecessary flag
obligations. Because the endpoint set is finite, the synthesizer now enumerates
endpoint subsets and uses exact candidate-language equality plus the theorem
verifier to select a genuine cover. Existing strict regressions are green.

The orbit/residue rule then removes the common-anchor/all-leading-powers
restriction. The leading `a`-orbit can use branch-specific `b` anchors, and the
admissible `n` values can be any finite/ultimately-periodic residue set induced
by the orbit. It strictly certifies a two-anchor parity fixture and an even-only
leading-parameter fixture where the previous automatic rule is inconclusive.

The bi-residue rule also permits the trailing exponent domain
`{m>=1 : delta(q,a^m b a)=final}` to be finite/ultimately periodic for each
middle endpoint `q`. A strict six-state fixture has exactly odd trailing
exponents; both previous rules are inconclusive and the new verifier returns
`VERIFIED_NO`. Candidate-language coverage is checked exactly by finite product
reachability, while the all-length proof uses the exhaustive `n<m`, `n=m`,
`n>m` cut formulas. Removing any required flag makes the certificate unavailable.

For transparency, a complete <=3-state diagnostic sees 464 exact NO instances
among 1,034 normalized cases and zero matches for these three-way shapes. This
is negative coverage evidence: the new calculus captures larger recurrent
arithmetic families, not the small census.

The language-theoretic frontier is now explicit. Non-overlap badness is a
terminal one-use backreference shape `A(B)_x C x`; overlap is bounded by
terminal nonmerging. ICALP 2026 gives near-linear *membership* for general
1-use backreferences, while FC[REG]-CQ universality is undecidable for a richer
formalism. Neither result settles regular-language containment in the terminal
one-copy union arising here. A direct invalid-computation transfer fails at the
obvious point: those gadgets use arbitrary trailing contexts/internal repeated
variables, whereas a BorderAvoid copy is anchored to the end of the candidate.
