### 2026-09-06 - Necessary hierarchy incomplete; a new exact NO class

Recorded by ChatGPT. Proposed C051 gives a five-state, three-flag flat binary
terminal instance with no witnesses but nonempty Necessary(L,D) for EVERY
finite budget. Candidates 1^n 0 1^m 0 are excluded by n<m, n=m, n>m. Choosing
m=n+1 leaves a unique violation of length n+1 and gap n+2. Increasing budgets
therefore cannot be a complete NO semiprocedure, although every existing
individual necessary emptiness certificate remains sound. C030 realizes the
example with 11 variables and 13 satisfiable normalized subtype constraints.

Proposed C052-C053 replace that failed strategy on a specified class: a finite
reverse padded-convolution machine handles arbitrary logical flags across
bounded delimited regular blocks. An automatic raw-input marker certificate
constructs a complete cover without adding markers. It proves the direct
five-state example NO using two schemas, while all its necessary languages
remain nonempty. Outside the certified class the procedure retains UNKNOWN.

Written proofs and E033/E034 are [indexed here](../DELIMITED.md), with a
[full proof note](../../notes/2026-09-06-delimited-convolution.md),
[block result](../../results/delimited-blocks.json), and
[raw-input result](../../results/marker-certificate.json).
These statements await independent review and are not Lean-checked. Finite
samples are implementation checks, not the all-length completeness argument.

The next question is a complete certificate beyond bounded marker structures.
Do not restart budget-emptiness completeness without a different invariant;
the fixed five-state counterexample already refutes it.

### 2026-09-06 - Saturating arbitrary target-free prefixes

Recorded by ChatGPT. Proposed C054-C056 extend C053's complete negative class
without assuming a globally bounded marker count. Before a fixed target-containing
reference suffix, early blocks have finite equality/hit observations and a
pending-pattern monitor. A powerset chooses all these observations relative to
one COMMON, existentially selected reference tuple. This prevents an unsound
independent choice of different reference words for different prefix edges.

The raw certificate allows marker cycles not reachable from any flag target.
Its finite reference cover and exact powerset search decide both positive and
negative fixtures excluded by C053. NO still requires every certified schema
empty; unsupported target cycles, unaligned formats and caps stay UNKNOWN.
The general negative-certificate problem remains unresolved.
