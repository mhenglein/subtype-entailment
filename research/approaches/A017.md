# A017: Bound essential repeated blocks

Current status, owner, and next step: [research tracker](../README.md). Metadata lives in [approaches.json](../approaches.json).

## Question and scope

Does every successful BorderAvoid instance have a witness describable by a fixed repetition skeleton whose size is effectively bounded by the instance encoding?

## Attempt history

### 2026-09-04 — Research-plan proposal

Recorded by Astra from the ten-angle outline. No decomposition theorem or block-deletion experiment has been attempted here.

First study words x u^k y, then two interacting repeated blocks. Record the transition effect of each block and all new borders crossing a deletion boundary. Test proposed deletion hypotheses against the independent witness predicate and minimize failures.

Investigate the transition monoid and [factorization forests](https://arxiv.org/abs/0710.5130) as ways to organize repeated behavior. The theorem supplies bounded-height decompositions for finite semigroups. It does not itself bound the number of relevant blocks or preserve our endpoint flags.

### 2026-09-04 — Exact loop-deletion obligation

Owner: Astra (`context_cut`).

An interior deletion between equal DFA states preserves the run and endpoint.
To preserve witnesses, every newly agreeing suffix pair that crosses the
join must lift to an agreeing pair before deletion. A written sufficient
condition makes this explicit. The three-state `001 -> 00` example shows
why repeated states alone fail.

This is a precise local proof obligation, not a finite skeleton theorem.
It supplies no bound on the number of essential blocks. See
[C019](../claims.md#c019) and the
[structure note](../../notes/2026-09-04-minimal-witness-structure.md).

### 2026-09-05 - Bounded exponent inside every terminal violation

C038 uses C036 to show that if an accepted terminal word has a proper suffix
agreement at positions i<j, with d=j-i and source-suffix length N, then
`floor(N/d) <= k-1`. Equivalently, the source suffix is `y^t r` for the gap
word `y`, a prefix `r` of `y`, and `t<=k-1`. The bound is sharp on unary
terminal paths.

This controls repetitions *inside* an arbitrarily long synchronized-pair
comparison, including cyclic residuals left UNKNOWN by C037. It does not bound
the gap length d, so it is not a word-length, budget, or finite-skeleton theorem.
The remaining problem can be viewed as bounded-use equality patterns under
regular path control. Related backreference-universality results are recorded
only as context; their languages are more general, so no undecidability
transfer is claimed.

E026 checks 2,000 seeded terminal automata, 11,631 accepted words, and 11,918
flagged agreements, plus the sharp family for k=2..8. See the
[proof](../../notes/2026-09-05-terminal-period-bound.md),
[experiment](../../experiments/check_terminal_period_bound.py), and
[result](../../results/terminal-period-bound.json).

### 2026-09-05 - Strict descent refuted by arithmetic synchronization

Recorded by ChatGPT. The proposed two-loop strengthening fails: C047 gives
k=2r+1 state instances and words (1110)^r whose shortest profile-safe loop
edit requires exactly r disjoint deletions. Seven states already need three.
There is no constant deletion bound independent of the state count.

More decisively, C046 refutes Q002 and Q003 themselves. Disjoint unary cycles
of lengths two and three, with flags enforcing equality of the block lengths,
have unique shortest witness 11111101111110 and exact B=7 on eight states.
Every profile-dominated accepted replacement has B>=7 and length>=14. No
number of loop deletions can shorten this word profile-safely. Earlier
k<=7, length<=12 falsification samples did not cover this example.

The r-block family has exact B=(r-1)(lcm(periods)+1), already superpolynomial
on flat graphs. A normalization theorem must allow arithmetic irreducible
base cases rather than promise descent whenever B>k-2. This does not refute
an effective finite skeleton cover, since unbounded exponents can represent
the modular synchronization exactly. The nonflat completeness question remains.

Written proofs and independent predicate/regular-model checks are in
[C046-C047](../claims.md#c046),
[the note](../../notes/2026-09-05-modular-synchronization.md), and
[E031](../../experiments/README.md#e031). Independent review is requested;
no Lean proof or unrestricted conclusion is claimed. Q002/Q003 records now
preserve their earlier evidence while marking the stated conjectures refuted.

### 2026-09-05 - Whole-word synchronization and large skeleton bodies

Recorded by ChatGPT; proposed C048-C050 and E032 await independent review.
Predecessor-tag flags force arbitrary binary blocks to be identical, not only
equally long. A 3*sum(n_i)+2r+1-state binary terminal construction has exactly
(E(u)00)^r as witnesses for common words of r supplied DFAs. This gives an
exact product-based decision for a genuinely nonflat subclass and an explicit
PSPACE-hardness reduction into the bottom/product signature using C030.
No unrestricted PSPACE upper bound is claimed.

A separate polynomial-size DFA list has singleton intersection C_d, the complete
list of d-bit binary numbers. Its compiled instance has a unique witness with
2^d distinct length-2d factors. Every fixed-word power skeleton containing that
witness needs body size at least 2^d/(2d), independently of exponent encoding.
Ordinary binary straight-line grammars require at least 2^d/(2d-1)
concatenation productions. This rules out polynomial-size descriptions in
those formats, not an effective finite cover or more expressive symbolic models.

E032 passes all 4,096 pairs of total two-state input DFAs, 120 random lists,
32,767 raw binary words, 3,785 block tuples, 196 full/reduced summary checks,
20 exact canonical models, and counting-family checks through d=6. Both word
predicates validate every returned product witness. Explicit caps stay UNKNOWN.
An initial harness call used the wrong reduced-bridge return signature and was
corrected before the saved run; no semantic conclusion was drawn from it.

## Result and limits

Success requires an effective normalization theorem plus correct preservation of every witness obligation. Combining such a theorem with a checked implementation of [A016](A016.md) could give a decision algorithm. Equality of transition effects alone is insufficient because deletion can create new borders.
