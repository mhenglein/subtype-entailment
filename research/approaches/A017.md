# A017: Bound essential repeated blocks

Current status, owner, and next step: [research tracker](../README.md). Metadata lives in [approaches.json](../approaches.json).

## Question and scope

Does every successful BorderAvoid instance have a witness describable by a fixed repetition skeleton whose size is effectively bounded by the instance encoding?

## Attempt history

### 2026-09-04 — Research-plan proposal

Recorded by Astra from the ten-angle outline. No decomposition theorem or block-deletion experiment has been attempted here.

First study words x u^k y, then two interacting repeated blocks. Record the transition effect of each block and all new borders crossing a deletion boundary. Test proposed deletion hypotheses against the independent witness predicate and minimize failures.

Investigate the transition monoid and [factorization forests](https://arxiv.org/abs/0710.5130) as ways to organize repeated behavior. The theorem supplies bounded-height decompositions for finite semigroups. It does not itself bound the number of relevant blocks or preserve our endpoint flags.

### 2026-09-04 — Exact loop-deletion obligation

Owner: Astra (`context_cut`).

An interior deletion between equal DFA states preserves the run and endpoint.
To preserve witnesses, every newly agreeing suffix pair that crosses the
join must lift to an agreeing pair before deletion. A written sufficient
condition makes this explicit. The three-state `001 -> 00` example shows
why repeated states alone fail.

This is a precise local proof obligation, not a finite skeleton theorem.
It supplies no bound on the number of essential blocks. See
[C019](../claims.md#c019) and the
[structure note](../../notes/2026-09-04-minimal-witness-structure.md).

### 2026-09-05 - Bounded exponent inside every terminal violation

C038 uses C036 to show that if an accepted terminal word has a proper suffix
agreement at positions i<j, with d=j-i and source-suffix length N, then
`floor(N/d) <= k-1`. Equivalently, the source suffix is `y^t r` for the gap
word `y`, a prefix `r` of `y`, and `t<=k-1`. The bound is sharp on unary
terminal paths.

This controls repetitions *inside* an arbitrarily long synchronized-pair
comparison, including cyclic residuals left UNKNOWN by C037. It does not bound
the gap length d, so it is not a word-length, budget, or finite-skeleton theorem.
The remaining problem can be viewed as bounded-use equality patterns under
regular path control. Related backreference-universality results are recorded
only as context; their languages are more general, so no undecidability
transfer is claimed.

E026 checks 2,000 seeded terminal automata, 11,631 accepted words, and 11,918
flagged agreements, plus the sharp family for k=2..8. See the
[proof](../../notes/2026-09-05-terminal-period-bound.md),
[experiment](../../experiments/check_terminal_period_bound.py), and

### 2026-09-06 - Recurrent references need shared word parameters

Recorded by ChatGPT. Base main: `bd4fde8f986a843fbc6f7b6f7ca626a5d0f67b0f`.
Selected Agent 2 from the ten-agent campaign; no additional agent was launched.
Target: test whether recurrent suffixes can be identified by their finite
transition action, endpoint, visited states, and complete agreement profile.

A five-state recurrent-target instance has exact witnesses 1^m 0^z 1^m 0,
m,z>=1. Its suffixes v_n=1^n0 all have the same proposed summary, but their
exact left-context languages are 1^n0^+, pairwise disjoint and nonempty. Thus
this summary is not substitutive, and literal residual-language inclusion has
an infinite antichain. A twelve-state copy extension retains the same issue
even for two length-ten suffixes with identical symbol counts, full transition
action, visited set, agreement profile, intrinsic budget, and repeated-suffix
length. The common prefix distinguishes them. These are exact counterexamples
to those stated quotient rules, not to saturation or decidability in general.

The repair for the benchmarks is a shared parameter, not independent values:
R_n=1^n0^+ and, for the binary copy case, R_u=E(u)00(01)* with the SAME u used
in the retained suffix E(u)00. A complete profile formula also proves that any
annotation of the fixed five-state table has a witness iff one of 1010, 10110,
11010 is a witness. This deliberately distinguishes contextual language
recognition from existence; the table is flat and the result is not advertised
as a new decision for the general recurrent-target class.

The deterministic regression checks 163,838 raw binary words across the two
fixtures, 30,705 left-context membership cases, 524,288 effective-flag/Bad
combinations, 22 exact canonical regular-model paths, and the strong collision.
The original core regression is unchanged. The all-length conclusions rest on
written proofs, not those finite tests. Independent review is pending and no
Lean or full repository build is claimed. No new global C/E IDs are allocated
in this scoped attempt; prior numbering and records are preserved.

### 2026-09-06 - Exact shared-word composition and universal family validation

Recorded by ChatGPT. Base main: `0318ff7b8750f64d72f0be87519782c1d91238de`.
Continuation of Agent 2; no other agent was launched. The previous residual
collisions motivate retaining common word assignments rather than identifying
suffixes by isolated profiles.

For arbitrary binary instances, a violation is exactly w=x d z with d z=z t
and regular path constraints locating the flagged states. Empty d and z cover
diagonal and empty-suffix cases. Finite template composition is exact after
alpha-renaming and conjoining interface equations. A proposed template family's
UNIVERSAL witness validity reduces to existential word equations with regular
constraints, using the classical external decidability theorem. This does NOT
decide whether a mixed family contains some witness; one bad member is not an
unrestricted NO certificate. Family inhabitance is checked separately.

A separate standard-library backend decides universal safety of every supplied
REGULAR family by finite transition-monoid exhaustion. It preserves one bad
periodic certificate rather than treating action equality as contextual
substitution. The product orbit bounds the needed exponent even for nonterminal
accepting states; terminality gives a sharper optional bound. It certifies the
infinite family 1 0^+ 1 0 and finds an invalid word in the broader mixed family.

Generic unbounded iteration of the template relations is undecidable: relations
(X,Y)->(X a_i,Y b_i) encode the shared-index Post correspondence question.
This is a restriction on a proposed general-purpose iteration theorem, NOT a
PCP reduction to BorderAvoid or a solution of Problem 1.7. Actual suffix
transitions need an additional invariant excluding that general mechanism.

The core run checks 12,218 word-equation identities, 15,240 path-regex cases,

oracles, and 256 cyclic terminal tables with 780 short-word cross-checks.
The 701 complete oracles comprise 381 terminal and 320 arbitrary-final cases,
with 2,403 words in total. Six canonical regular-model paths and an intentional

## Result and limits

Success requires an effective normalization theorem plus correct preservation of every witness obligation. Combining such a theorem with a checked implementation of [A016](A016.md) could give a decision algorithm. Equality of transition effects alone is insufficient because deletion can create new borders.
